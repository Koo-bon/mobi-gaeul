# 꿀밤 때리기 — 설계

## 목적
대행사 실무자가 짜증 나는 브랜드 이름을 적어 넣고 10초간 꿀밤을 때려 분을 푸는 웹 게임.
팀 슬랙에 링크 하나로 공유할 수 있어야 한다.

## 게임 규칙
1. 브랜드 이름을 입력하고 시작한다. (1~12자, 빈 값 불가)
2. 이름이 이마에 박힌 픽셀 머리통이 등장한다.
3. 10초 동안 화면을 클릭/탭하면 손가락이 날아와 꿀밤을 때린다.
   - 머리가 휘청이고, 별이 튀고, 혹이 하나 생긴다.
4. 콤보: 직전 타격으로부터 500ms 안에 때리면 배수가 1씩 오른다(최대 x20). 끊기면 1로 리셋.
5. 점수 = 타격마다 현재 배수를 더한 값. 격노 모드에서는 2배.
6. 분노 게이지: 타격마다 차고, 시간당 조금씩 빠진다. 가득 차면 격노 모드 3초
   (화면 붉어짐·화면 흔들림·점수 2배). 끝나면 게이지 0.
7. 10초가 끝나면 결과 화면: 브랜드명, 총 타격 수, 최고 콤보, 분노 지수(%), 등급 한 줄.
8. 결과 화면에서 "다시" 또는 "다른 브랜드".

## 구현
- `kkulbam/index.html` — 화면·스타일·입력 폼
- `kkulbam/game.js` — 캔버스 렌더링과 게임 로직
- 외부 라이브러리 없음. 이미지 에셋 없음(머리통은 캔버스에 직접 그린다).
- 폰트는 기존 레포의 `fonts/Galmuri11.woff2`를 재사용한다.
- 효과음은 WebAudio로 합성한다(노이즈 버스트 + 짧은 사인). 오디오 파일 없음.
- 캔버스 논리 해상도 360x480, `image-rendering: pixelated`로 확대.

## 검증
`kkulbam/test.mjs` — 점수·콤보·분노 게이지 순수 로직을 assert로 검사한다.

## 배포
기존 레포(Koo-bon/mobi-gaeul)의 GitHub Pages. 루트는 기존 "은행 주의보"이므로
새 게임은 `/kkulbam/` 경로로 서비스한다.

## 넣지 않는 것
랭킹(서버 필요), 결과 카드 이미지 공유, 무기 선택, 브랜드 말대꾸 대사.
필요해지면 그때 추가한다.
